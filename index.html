김실장 영상 업로드

Kim Siljang Video Uploader · 개인용 수업 영상 업로드 도구

이 도구는 수학 강사 웅록이 직접 촬영한 본인의 수업 영상을 본인의 유튜브 채널에 올리기 위해 만든 개인용 프로그램입니다. 다른 사람의 계정이나 영상은 다루지 않습니다.

하는 일

  • 강사 본인의 드롭박스 폴더에 넣은 수업 영상 파일을 YouTube Data API(videos.insert)로 강사 본인 채널에 업로드합니다.
  • 영상 제목과 설명(문항별 시작 시각)을 함께 등록합니다.
  • 요청하는 권한은 youtube.upload 하나뿐입니다. 영상 삭제·수정, 시청 기록, 구독 정보 등에는 접근하지 않습니다.

사용자

사용자는 채널 소유자인 강사 본인 한 명입니다. 일반에 공개된 서비스가 아닙니다.

이 도구는 YouTube API 서비스를 사용합니다. 사용 시 YouTube 서비스 약관에 동의하게 됩니다.

English

A private, single-user tool that uploads the owner's own lecture videos to the owner's own YouTube channel via the YouTube Data API (scope: youtube.upload only). It is not offered to the public and does not access any other user's data.
